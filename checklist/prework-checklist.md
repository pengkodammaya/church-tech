# Why this matters

The workshop's first 30 minutes are spent installing tools. Every item you finish at
home is ten extra minutes of building with your group on the day. Budget 45 quiet minutes.

# The checklist

- [ ] **1. Node.js installed** — from nodejs.org, choose LTS, default options, then open a NEW PowerShell and run `node --version` (expect v22 or similar)

- [ ] **2. opencode installed** — in PowerShell: `npm install -g opencode-ai`, then check `opencode --version`

- [ ] **3. OpenCode Zen key connected** — account at opencode.ai/auth, then `opencode auth login` → OpenCode → paste key; test: run `opencode` and say hello

- [ ] **4. Backup key connected** — free account at openrouter.ai → create API key → `opencode auth login` → OpenRouter → paste

- [ ] **5. Accounts created** — GitHub (`github.com/signup`) and Vercel (`vercel.com/signup` → Continue with GitHub → Hobby plan)

# Also bring / know

- [ ] Laptop charger
- [ ] Both API keys emailed to yourself
- [ ] Church content for the website lab: name, service times, address, phone/email, one welcome sentence, one favourite verse

# If anything fails at home

Do not burn your evening on it — message the organiser tonight with a screenshot of the
error. On the day we pair up anyone whose laptop fights back, so nobody misses out.
